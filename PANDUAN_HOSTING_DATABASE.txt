========================================================================
PANDUAN LENGKAP HOSTING PROYEK (MODE DOCKER) & KONEKSI DATABASE MSS SERVER
========================================================================
Diperbarui untuk: Tracer Study SMK Swasta Budhi Darma Indrapura - Port 9004 & Database mss-db

Panduan ini mencakup langkah demi langkah meng-hosting proyek Laravel dari GitHub
(https://github.com/Afiqq19/tracer-study.git) ke server Linux Toshiba menggunakan DOCKER,
terhubung ke Database Panel (mss-db), dan di-onlinekan via Cloudflare Tunnel.

------------------------------------------------------------------------
LANGKAH 1: SIAPKAN DATABASE KOSONG DI PANEL
------------------------------------------------------------------------
1. Buka MSS Server Panel di browser:
   https://panel.xie.my.id
2. Masuk ke menu "Database Manager" di sebelah kiri.
3. Di tab "Visual Explorer", klik tombol bulat warna biru dengan tanda Plus (+).
4. Masukkan nama database untuk Tracer Study:
   Nama DB: db_tracerstudy
5. Pada pilihan Mesin Database, pilih wadah:
   Mesin: mss-db
6. Selesai! Database kosong db_tracerstudy sudah siap digunakan.

------------------------------------------------------------------------
LANGKAH 2: MASUK KE SERVER & CLONE PROYEK
------------------------------------------------------------------------
1. Masuk via SSH ke server Linux Toshiba Anda (Anda sudah berhasil login!):
   mss@servermss:~$
2. Masuk ke direktori web server:
   cd /var/www/
3. Unduh repositori dari GitHub:
   git clone https://github.com/Afiqq19/tracer-study.git
4. Masuk ke folder proyek:
   cd tracer-study

------------------------------------------------------------------------
LANGKAH 3: KONFIGURASI DOCKER (DOCKERFILE & DOCKER-COMPOSE)
------------------------------------------------------------------------
(CATATAN: File Dockerfile dan docker-compose.yml SUDAH DISEDIAKAN langsung di dalam repositori GitHub, jadi Anda tidak perlu membuatnya manual lagi!)

1. File `Dockerfile`:
   PHP 8.3 Apache + Ekstensi MySQL, PgSQL, GD, Zip + Composer.

2. File `docker-compose.yml`:
   Mengarahkan Port 9004 host ke Port 80 Apache container:
   - Container Name: web_tracerstudy
   - Port: 9004:80
   - Network: mss-server-panel_mss-network

------------------------------------------------------------------------
LANGKAH 4: HUBUNGKAN KONEKSI DATABASE (.ENV)
------------------------------------------------------------------------
1. Buat file .env dari template:
   cp .env.example .env
2. Edit file .env:
   nano .env
3. Sesuaikan konfigurasi database agar terhubung langsung ke wadah mss-db:

   APP_NAME="Tracer Study SMK Swasta Budhi Darma Indrapura"
   APP_ENV=production
   APP_DEBUG=false
   APP_URL=https://projek1.xie.my.id
   APP_TIMEZONE=Asia/Jakarta

   DB_CONNECTION=mysql
   DB_HOST=mss-db
   DB_PORT=3306
   DB_DATABASE=db_tracerstudy
   DB_USERNAME=root
   DB_PASSWORD=root_secret_pass

   (Catatan: Password "root_secret_pass" sudah sesuai dengan password default container mss-db pada server MSS Anda!)
4. Simpan perubahan: Tekan CTRL+O, Enter, lalu CTRL+X.

------------------------------------------------------------------------
LANGKAH 5: JALANKAN DOCKER, KUNCI AKSES, & MIGRATE + SEED
------------------------------------------------------------------------
1. Bangun dan hidupkan container Docker:
   docker compose up -d --build

2. Gabungkan jaringan container ke jaringan panel MSS (agar container mss-db terbaca):
   docker network connect mss-server-panel_mss-network web_tracerstudy

3. Berikan hak akses file .env dan storage agar tidak permission denied:
   docker exec -u root -it web_tracerstudy chown -R www-data:www-data /var/www/html
   docker exec -u root -it web_tracerstudy chmod 777 /var/www/html/.env
   docker exec -u root -it web_tracerstudy chmod -R 777 /var/www/html/storage /var/www/html/bootstrap/cache

4. Jalankan dependensi, pembuatan App Key, migrasi database, dan seeder:
   docker exec -it web_tracerstudy composer install --no-interaction --prefer-dist --optimize-autoloader
   docker exec -it web_tracerstudy php artisan key:generate
   docker exec -it web_tracerstudy php artisan config:clear
   docker exec -it web_tracerstudy php artisan migrate --force
   docker exec -it web_tracerstudy php artisan db:seed --force
   docker exec -it web_tracerstudy php artisan storage:link

------------------------------------------------------------------------
LANGKAH 6: AKSES WEBSITE (LOKAL & DOMAIN ONLINE)
------------------------------------------------------------------------
1. Akses Lokal Server:
   Buka browser di jaringan lokal / WiFi yang sama:
   http://192.168.1.100:9004

2. Online ke Domain Publik (via Cloudflare Zero Trust Tunnel):
   - Buka Cloudflare Zero Trust Dashboard (Networks > Tunnels).
   - Masuk ke tunnel server Toshiba Anda.
   - Tambahkan Public Hostname baru:
       Domain: projek1.xie.my.id
       Service Type: HTTP
       URL: 192.168.1.100:9004
   - Klik Save Hostname.
   - Website Anda langsung online di: https://projek1.xie.my.id !
